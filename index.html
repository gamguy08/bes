  • 키 관리 시스템: 슬롯 기반 키 저장/생성/삭제, 키 쌍 생성(RSA/ECC), 대칭키 생성(AES)

  • CLI 테스트 도구: hsmtest 명령어 기반 HSM 기능 검증 도구 개발 (DMA 순환 버퍼 기반)
